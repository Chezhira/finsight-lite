# FinSight Lite Screenshot Checklist

After launching the app with:

```bash
streamlit run app/streamlit_app.py
```

Open:

```text
http://localhost:8501
```

Capture and save the following screenshots:

1. `01_executive_overview.png`

   - KPI cards visible
   - Revenue, COGS, gross profit, operating profit proxy, cash, anomalies visible

2. `02_pnl_budget_vs_actual.png`

   - P&L and budget variance table or chart visible

3. `03_anomalies.png`

   - Anomaly summary and anomaly table visible

4. `04_cfo_commentary.png`

   - CFO-style commentary visible

5. `05_data_quality.png`

   - DQ summary and exception table visible
